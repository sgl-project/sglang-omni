# 第一次用 Voxt：五分钟装好

[English](en/first_time.md)

刚听说 Voxt，想今天就开始用语音输入。整个过程三步，每步都有单独的教程。

1. [安装 Voxt 和下载语音识别模型](start.md)：下载 2.1.2 正式版，装好并允许麦克风和辅助功能，下载推荐的本地语音识别模型。
2. [用自己的 API Key 配置语言模型（BYOK）](byok.md)：翻译、改写和转录润色都需要一个语言模型。
3. 打开一个空白文本框，轻按右 `⌥ Option` 说一句话，再轻按一次。文字出现在光标处，就可以开始用了。

装好以后，按手头的事挑一篇场景教程：回邮件、写草稿、翻译、写对人名，见[教程首页](index.md)的「按场景上手」。
