# 把写好的段落改得更好

[English](en/polish_draft.md)

写好了一段话，想让它更短、更清楚或更正式，不想自己重写。先[配置语言模型](byok.md)，并[下载语音识别模型](start.md#下载-asr)。

1. 选中要改的文字，轻按 `⌃ Control` + 右 `⌥ Option`，说出要求，比如「缩短一半，语气正式一些」，再按一次快捷键。
2. 答案卡片给出改写结果。满意后点**插入**替换选区，或点**复制**自行粘贴。
3. 还想再改就点**继续**，再说一句，比如「再短一点」，卡片会接着改。

选中文字也可以问问题（「这段话有没有重复的论点」），不选中文字则直接说出想写的内容。更多写法见[改写教程](rewrite.md)。当前快捷键以**改写**页为准。
