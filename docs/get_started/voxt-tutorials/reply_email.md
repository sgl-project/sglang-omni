# 看懂并回复一封英文邮件

[English](en/reply_email.md)

收到一封英文邮件，想弄懂它的意思，再不动键盘回一封得体的英文。先[配置语言模型](byok.md)，并[下载语音识别模型](start.md#下载-asr)。

1. **看懂来信**。在邮件 App 里选中正文，轻按 `⌃ Control` + 右 `⌥ Option`，说「这封邮件讲了什么，需要我做什么」，再按一次快捷键。答案卡片会用中文解释。
2. **口述回复**。在回复框点一下放好光标、不选中文字，轻按 `⇧ Shift` + 右 `⌥ Option`，用中文说出回复内容，再按一次。英文译文直接输入到光标处。
3. **润色回复**。选中刚写好的英文，按 `⌃ Control` + 右 `⌥ Option`，说「更礼貌一些」，在答案卡片上点**插入**替换选区。还想再改就点**继续**，再说一句要求。

第 1 步用的是[改写](rewrite.md)：选中文字后，说的任何问题都会对照选区回答。第 2 步用的是[翻译](translate.md)。当前快捷键以**改写**和**翻译**页为准。

## 交给 Agent

> 按本页确认 Voxt 的语音识别模型和语言模型可用。打开我指定的邮件并选中正文，等我口述问题；在回复框里等我口述回复内容。不替我点发送，发不发由我决定。
