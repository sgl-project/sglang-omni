# 让 Voxt 看着屏幕帮你写

[English](en/screenshot_context.md)

要用的信息在屏幕上的图片里（比如一张邀请函），想让 Voxt 照着它写回复，不用自己重新打字。先[配置一个能读图的语言模型](byok.md)，并[下载语音识别模型](start.md#下载-asr)。

1. 打开 Voxt 的**设置 → 隐私**，打开**发送截图**。第一次使用时按提示在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”里允许 Voxt。
2. 把邀请函的窗口放在屏幕上，轻按 `⌃ Control` + 右 `⌥ Option`，说「照着这个邀请函写一封接受邀请的回复」，再按一次快捷键。
3. 开始说话时，Voxt 会截取当前窗口一起发给语言模型，答案卡片参照屏幕上的内容来写。核对时间、地点没有抄错后点**插入**。

卡片上会标明这次请求附带了截图。不开这个开关时，Voxt 只发送你选中或口述的文字。改写本身的用法见[改写教程](rewrite.md)。

## 交给 Agent

> 按本页在设置里打开发送截图；需要系统授权时停下来等我操作。确认我指定的窗口在屏幕上，等我口述要求。把答案卡片留给我核对，由我决定是否插入。
