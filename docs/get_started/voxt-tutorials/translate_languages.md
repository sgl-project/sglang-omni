# 把同一段话翻成另一种语言

[English](en/translate_languages.md)

想说一遍或写一遍，就得到另一种语言的版本。先[配置语言模型](byok.md)；语音翻译还需要[下载语音识别模型](start.md#下载-asr)。

1. **翻译说的话**。在输入框放好光标、不选中文字，轻按 `⇧ Shift` + 右 `⌥ Option`，把话说完再按一次。译文直接输入到光标处。
2. **翻译写好的文字**。选中文字，按 `⇧ Shift` + 右 `⌥ Option`。译文显示在答案卡片上，点**插入**替换选区，或点**复制**自行粘贴。
3. **换目标语言**。在**翻译**页改**目标语言**；翻译结果显示在卡片上时，也可以点卡片上的语言直接换一种，再插入。

第一个模型失败时自动换用的**备用模型**、「人名不翻译」一类的**你的规则**，见[翻译教程](translate.md)。当前快捷键以**翻译**页为准。
