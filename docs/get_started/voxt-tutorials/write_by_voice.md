# 不动键盘写一段文字

[English](en/write_by_voice.md)

写聊天消息或笔记，想说得比打字快。先[下载语音识别模型](start.md#下载-asr)。

1. 在输入框点一下放好光标。轻按右 `⌥ Option`，自然地说完要写的话，再轻按右 `⌥ Option`。
2. 文字出现在光标处。在**转录**页选用了[语言模型](byok.md)时，Voxt 会先去掉口头语、整理好标点再输入。
3. 人名或术语总是写错时，把它加进[词典](names_right.md)，下次就写对了。

<div class="vx-anim" data-scene="dictate" data-lang="zh"></div>

按 `Esc` 可以随时取消。再粘贴一次上一条结果、识别失败后重试等细节见[转录教程](transcribe.md)。当前快捷键以**转录**页为准。

## 交给 Agent

> 按本页检查转录快捷键和语音识别模型，打开一个空白文本框放好光标，等我口述。结束后核对文字是否出现在光标处，不替我发送。
