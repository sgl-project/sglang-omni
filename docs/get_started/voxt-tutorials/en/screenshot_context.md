# Let Voxt see the screen while it writes

[中文](../screenshot_context.md)

The details you need are in an image on screen — an invitation, say — and you want a reply written without retyping them. First [set up a language model that reads images](byok.md) and [download a speech model](start.md#download-a-speech-model).

1. Open Voxt's **Settings → Privacy** and turn on **Send a screenshot**. The first time, allow Voxt under "System Settings → Privacy & Security → Screen & System Audio Recording" as prompted.
2. Keep the invitation's window on screen, tap `⌃ Control` + Right `⌥ Option`, say "write a reply accepting this invitation", and press the shortcut again.
3. When you start speaking, Voxt sends a screenshot of the window with the request, so the answer card can use what is on screen. Check that times and places were read correctly, then click **Insert**.

The card marks when a screenshot went with the request. With the switch off, Voxt sends only the text you selected or dictated. Rewrite itself is covered in the [Rewrite tutorial](rewrite.md).

## For agents

> Following this page, turn on Send a screenshot in Settings; stop and wait for me if a system permission prompt appears. Make sure the window I name is on screen, then wait for my spoken instruction. Leave the answer card for me to check; I decide whether to insert it.
