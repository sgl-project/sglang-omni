# Rewrite text with Voxt

[中文](../rewrite.md)

Select some text and tell Voxt by voice how to change it. First [set up a language model](byok.md) and [download a local speech model](start.md#download-a-speech-model).

1. On Voxt's **Rewrite** page, check that a speech model and a language model are chosen. In an empty document, type “can't make it tomorrow, let's pick another time” and select it.
2. Tap `⌃ Control` + Right `⌥ Option`, say “make it a short, polite message to reschedule”, and press the same shortcut again to finish.
3. Read the answer card. Click **Insert** to replace the selection, or **Copy** to paste it yourself. To change it further, click **Continue** and say, for example, “add a thank-you”.

With nothing selected, you can also say what to write and Voxt writes new text. The current shortcut is the one on the **Rewrite** page.

## For agents

> Following this page, check that Voxt's Rewrite uses a working speech model and language model. In a new document, add a harmless sample sentence and select it, then wait for me to say how to change it. Leave the answer card for me to review; I decide whether to insert it.
