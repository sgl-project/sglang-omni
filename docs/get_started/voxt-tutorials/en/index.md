# Voxt tutorials

[中文](../index.md)

For a first install, choose the 2.0.3 release. Once Voxt is installed, open the tutorial you need. Each one has its own link you can share, and each step has a short looping animation; click it to pause.

<div class="vx-anim" data-scene="dictate" data-lang="en"></div>

- [Install Voxt and download a speech model](start.md)
- [Set up a language model with your own API key (BYOK)](byok.md)
- [Translate what you say or the selected text](translate.md)
- [Transcribe what you say at the cursor](transcribe.md)
- [Rewrite the selected text by voice](rewrite.md)

| Feature | Default shortcut |
|---|---|
| Transcribe | Right `⌥ Option` |
| Translate | `⇧ Shift` + Right `⌥ Option` |
| Rewrite | `⌃ Control` + Right `⌥ Option` |

Press `Esc` to cancel at any time. Model names, addresses and API keys are hidden in the animations.
