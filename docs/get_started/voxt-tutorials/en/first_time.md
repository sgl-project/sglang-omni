# New here: set up Voxt in five minutes

[中文](../first_time.md)

You just heard about Voxt and want to start dictating today. Three steps, each with its own tutorial.

1. [Install Voxt and download a speech model](start.md): get the 2.1.2 release, allow the microphone and accessibility, and download the recommended on-device speech model.
2. [Set up a language model with your own API key (BYOK)](byok.md): Translate, Rewrite and transcription clean-up all need a language model.
3. Open an empty text field, tap Right `⌥ Option`, say a sentence, and tap it again. When the text appears at the cursor, you are ready.

Once set up, pick the scenario that matches what you are doing — answering email, drafting, translating, getting names right — under "Learn by scenario" on the [tutorials home](index.md).
