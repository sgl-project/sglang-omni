# 让 Voxt 写对人名和术语

[English](en/names_right.md)

Voxt 总把同事的名字或产品术语写错，每次都要手改。把它加进词典，一次就好。

1. 打开 Voxt 主窗口，在侧栏进入**词典**，点**添加词条**。
2. **词条**填正确的写法，比如「Kubernetes」；**别名**填语音识别常听成的写法，比如「库伯奈特斯」。保存。
3. 再说一次刚才那句话，名字就写对了。词条会发给语音识别模型留意，语言模型也会按词条的写法输出。

词条很多时，在**词典**页点**导入…**，可以一次导入 CSV 或词条列表。某条写法只在特定情况下适用时，把规则写进**个人词典**的 Markdown 说明，它会随请求发给语言模型。词典对[转录](transcribe.md)、[翻译](translate.md)和[改写](rewrite.md)都生效。
