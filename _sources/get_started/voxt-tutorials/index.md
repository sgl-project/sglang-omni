# Voxt 上手教程

[English](en/index.md)

首次安装请选 2.0.3 正式版。装好以后，按需要打开对应教程。每篇都是单独的链接，可以直接转发；每一步下面有一段循环小动画，点一下暂停。

<div class="vx-anim" data-scene="dictate" data-lang="zh"></div>

- [安装 Voxt 和下载语音识别模型](start.md)
- [用自己的 API Key 配置语言模型（BYOK）](byok.md)
- [翻译说的话或选中的文字](translate.md)
- [把说的话转录到光标处](transcribe.md)
- [用语音指令改写选中的文字](rewrite.md)

| 功能 | 默认快捷键 |
|---|---|
| 转录 | 右 `⌥ Option` |
| 翻译 | `⇧ Shift` + 右 `⌥ Option` |
| 改写 | `⌃ Control` + 右 `⌥ Option` |

按 `Esc` 随时取消。动画里的模型名、地址和 API Key 都已打码。
