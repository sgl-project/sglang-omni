Qwen3-TTS#

Qwen3-TTS is a multi-codebook text-to-speech model family that streams 24 kHz speech in 10 languages. The 12Hz checkpoint name refers to the codec frame rate. SGLang-Omni serves Base for voice cloning, CustomVoice for built-in speakers, and VoiceDesign for voices described in natural language through the OpenAI-compatible /v1/audio/speech endpoint.

Prerequisites#

Install sglang-omni by following Installation. The following example uses Linux with an NVIDIA GPU.

Install the Qwen3-TTS dependencies in the server environment:

apt-get update && apt-get install -y sox
uv pip install --no-deps sox einops
uv pip install --no-deps qwen-tts==0.1.1

See dependency troubleshooting if imports fail.

Server Configuration#

This example uses 1.7B CustomVoice:

sgl-omni serve \
  --model-path Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice \
  --config examples/configs/qwen3_tts_1_7b_customvoice.yaml \
  --port 8000

The first startup will take several minutes for compilation and warmup. Then, in another terminal, run the following command and wait until /health returns HTTP 200:

curl -i http://localhost:8000/health

Synthesizing Speech#

curl --fail-with-body http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice",
    "input": "Hello! This is Qwen3-TTS running with SGLang-Omni.",
    "voice": "Ryan",
    "language": "English",
    "instructions": "Speak clearly and calmly."
  }' \
  --output output.wav

Open output.wav in an audio player. The response is WAV audio by default. For Python or the OpenAI SDK, use the TTS client examples.

Use CustomVoice if you do not have a reference clip. For other hardware, such as Ascend NPU or Intel XPU, or for the native Apple Silicon runtime, see platform deployment.

Voice modes#

CustomVoice#

CustomVoice uses voice to select a built-in speaker. The 1.7B model also supports speaking-style control through instructions, while the 0.6B model is primarily intended for speech synthesis with built-in speakers.

List the available speakers:

curl --fail-with-body http://localhost:8000/v1/audio/voices

The 0.6B checkpoint also supports built-in speakers, but reliable style control requires 1.7B. See speaker and dialect behavior for details.

Voice cloning#

Voice cloning requires a Base checkpoint with reference audio or a precomputed speaker embedding. See Voice cloning in TTS Model Usage for setup and request examples.

VoiceDesign#

VoiceDesign generates a voice from a description in instructions and requires the 1.7B VoiceDesign checkpoint. See Voice design in TTS Model Usage for setup and request examples.

Streaming#

With the CustomVoice server running, send a streaming request:

curl --fail-with-body -N http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice",
    "input": "Hello! This is Qwen3-TTS running with SGLang-Omni.",
    "voice": "Ryan",
    "language": "English",
    "stream": true,
    "response_format": "wav"
  }' \
  --output streaming.wav

This saves the streamed audio to streaming.wav.

All three voice modes support streaming. For detailed examples, see TTS streaming examples, SSE, and WebSocket.

The default chunk schedule favors early audio. If playback stalls under load, see first-audio chunk tuning.

Common options#

With the 1.7B CustomVoice server running, customize the language, speaking style, generation limit, and sampling seed:

curl --fail-with-body http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice",
    "input": "你好，欢迎使用 SGLang-Omni。",
    "voice": "Vivian",
    "language": "Chinese",
    "instructions": "用平静、自然的语气说话。",
    "max_new_tokens": 512,
    "seed": 42
  }' \
  --output chinese-speech.wav

Reaching max_new_tokens can truncate speech. A fixed seed does not guarantee byte-identical audio; see deterministic inference.

See Qwen3-TTS parameters for defaults and model-specific controls, and the shared TTS API for common request fields.

Known limitations#

  • Base requires a reference voice. Provide reference audio or a speaker embedding. Include the audio transcript for better cloning quality. For text-only synthesis, use CustomVoice or VoiceDesign.

  • Speech may repeat or stop before the sentence ends. Repetition can occur on some inputs. Set max_new_tokens to limit generation, but allow enough tokens for the full sentence. Check the X-Finish-Reason response header: length means generation reached the limit, so the audio may be incomplete. See finish reasons and benchmark results.
