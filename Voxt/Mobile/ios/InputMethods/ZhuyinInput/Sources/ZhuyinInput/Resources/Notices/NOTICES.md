# Zhuyin input sources

McBopomofo 3.1.1, commit f5ba010ce8795d283ee336ca7d16380f200bd2ec:
https://github.com/openvanilla/McBopomofo

Four C++ translation units and their headers are copied without modification
into ios/McBopomofoEngine, shared with the pinyin keyboard.
Each retains its MIT notice; the root MIT text is McBopomofo-MIT.txt.
The data artifact is generated by `make data.txt` in Source/Data at that commit.
DictionaryManifest.json records the input and output SHA256 values.

McBopomofo's Source/Data/README.md identifies BPMFMappings.txt as modified from
libtabe's tsi.src. libtabe-BSD.txt is the complete COPYING from
https://github.com/kcwu/libtabe/tree/ea382a829c916f2cceda2022afdf8e8471e6e7b5
and contains both TaBE and Academia Sinica notices. McBopomofo does not identify
the historical tsi.src revision used for its modifications.
