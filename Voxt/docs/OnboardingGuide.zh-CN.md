# 六步交互引导

## 流程

1. **权限**：麦克风、辅助功能；现有系统听写配置按需检查语音识别权限。不再请求输入监控或屏幕录制；普通输出设备静音不要求系统音频录制，会议系统音源开始采集时再按需授权。麦克风反馈不作为额外通关条件。
2. **模型**：语音模型就绪即可继续，翻译文字模型可选。支持本地、远程及混合配置。
3. **语音输入**：提供可照读的示例和真实快捷键，在体验输入框中完成一次实际转录。
4. **语音翻译**：选择不同于示例的目标语言，照读示例并获得真实译文。
5. **选中翻译**：选中提供的示例，使用同一个翻译快捷键；按照用户现有设置显示结果窗口或替换选区。
6. **探索更多**：改写、笔记、会议、文件转录四张介绍卡片，展示实际快捷键或入口，点击「开始使用」结束。

三个体验步骤均可稍后体验。最后一页不要求继续配置其他功能。

## 配置安全

- 打开引导只读取 `FeatureSettingsStore`，不统一重写功能模型。
- 本地/远程标签仅切换浏览内容。
- 模型选择存入 `OnboardingModelDraft`，点击「继续」后合并到最新设置，关闭引导则丢弃未确认的模型选择。
- 选择语音模型只修改转录 ASR；选择翻译模型只修改翻译模型。不重置增强开关、笔记、改写或会议配置。
- 翻译 ASR 未就绪时，提供明确的「复用语音输入的识别模型」操作，不自动覆盖现有翻译 ASR。
- 模型下载、服务凭据保存、快捷键修改和权限授权是用户主动发起的操作，不随关闭引导回滚。
- 未完成的模型下载可继续后台运行。翻译模型下载不会阻止基础语音输入。
- 旧步骤 ID 会映射到新的相关步骤；已完成的用户不会因升级被强制重走引导。

## 真实体验状态

`OnboardingPracticeState` 只接收匹配当前步骤、来源窗口及 session ID 的真实业务事件：

```text
准备 → 启动中 → 正在聆听 → 正在处理 → 输出成功
                                     ↘ 失败/取消 → 重试
```

- 不根据检测到按键、选择了文字、手动编辑了输入框来判定成功。
- 非空输出且成功写入，或选中翻译结果已展示，才完成本次体验。
- 不要求用户逐字读对示例，不用模拟译文冒充真实输出。
- 其他窗口、其他业务和上一次会话的回调不能完成当前步骤。
- 启动/处理中可取消；录音中提供「说完了」和真实停止快捷键提示。
- 会话进行中禁用前后翻页，避免迟到的输出写入下一步。
- 关闭引导会取消它所关联的活动会话，不取消来自其他应用的会话。
- 成功后不自动跳页，允许查看结果、重试或继续。
- 不持久化教程中的示例结果或增加遥测；正常业务的历史记录仍遵循原有设置。

## 自动化回归

`VoxtTests/OnboardingGuideTests.swift` 覆盖六步导航、旧进度迁移、配置草稿的最小范围合并，以及真实会话的成功、失败、取消、重试和迟到回调隔离。

在 macOS 上运行：

```bash
xcodebuild test -project Voxt.xcodeproj -scheme Voxt \
  -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO \
  -only-testing:VoxtTests/OnboardingGuideTests \
  -only-testing:VoxtTests/OnboardingPreferenceManagerTests \
  -only-testing:VoxtTests/OnboardingSupportTests
```

## macOS 人工验收

- [ ] 新用户只安装 ASR、不安装文字模型，可以语音输入并跳过翻译。
- [ ] 本地、远程、混合模型用户反复重开引导，原设置均不改变。
- [ ] 切换模型标签、关闭未确认的模型页不改变模型路由。
- [ ] 权限拒绝、从系统设置返回、麦克风无声/断开均可恢复。
- [ ] 下载失败、暂停、恢复及更换下载路径有明确反馈。
- [ ] 默认快捷键、长按、单击、双击和自定义快捷键均显示正确；默认转录修饰键可停止翻译录音。
- [ ] 三个体验步骤使用真实链路；输入框聚焦、录音反馈、结果写入及成功按钮正常。
- [ ] 手动输入文字、只按快捷键、只选择文字均不能误判成功。
- [ ] 选中翻译分别验证「显示结果窗口」开启和关闭的行为。
- [ ] 翻译功能关闭、ASR 不可用、文字模型未安装、凭据无效时可明确补齐配置或跳过。
- [ ] 启动中/处理中取消、关闭窗口、失败重试，不出现迟到结果或残留录音。
- [ ] 引导在后台时，其他应用中的录音不会被识别为教程体验。
- [ ] 880×600 窗口下中英日文案不遮挡主要按钮；减少动态效果设置生效。
