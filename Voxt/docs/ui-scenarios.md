# UI 场景：2.0.1 上线的功能

每个场景写明：用户从哪里开始、做什么、界面上应该看到什么，以及容易出错的边界情况。“覆盖”一项列出已经检查这个场景的自动测试（`go test -run <名字> .`）和 [manual-test.md](manual-test.md) 的小节；修改这些功能的界面时，先对照这里的“应看到”，再跑对应的测试。功能本身的说明见 [CHANGELOG.md](../CHANGELOG.md) 的 2.0.1 一节，行为与 1.x 的对照见 [behavior.md](behavior.md)。

## S1. 设置一个远程语言模型

- **起点**：刚装好，语音识别模型已下载，还没有语言模型。首页的通知卡片写着要先设置语言模型。
- **操作**：点通知卡片上的按钮，进入语言模型页 → 在“在线服务”里点 DeepSeek → 粘贴 API key、选模型 → 点“测试” → 保存。
- **应看到**：测试连接后在对话框里显示结果；保存后 DeepSeek 卡片显示模型名，转录、翻译、改写页的模型菜单里出现 DeepSeek，通知卡片消失。
- **边界**：在对话框外点一下或按 Esc 不会丢掉刚粘贴的 key；出错提示里不会出现 key；key 只保存在钥匙串里。
- **覆盖**：`TestRemotePage`、`TestRemoteModelEndToEnd`、`TestRemoteErrorKeepsNoKey`、`TestOnboardingLanguageModelGuide`；手测 1.6b、9.10。

## S2. 从 Voxt 1.x 导入

- **起点**：Mac 上有 Voxt 1.x 的数据，第一次打开 2.x。
- **操作**：在设置引导的第一张卡片上点“导入”，看完结果后继续引导。
- **应看到**：结果按“已导入 / 待处理 / 未导入”分组：词典的条数、历史条数、语言模型和语音服务的个数、提示词；需要重新粘贴 key 的服务逐个列在“待处理”里，并带“完成设置”的入口；导入后卡片不再出现。
- **边界**：替换词变成“听成”别名，停用的词条保持停用；会议记录和空记录不导入，并在结果里说明；1.x 的 Options JSON 会放进“请求参数”的 `options` 里；地址或模型可能不兼容的服务，会提示用户检查。
- **覆盖**：`TestImportLegacySettings`、`TestImportReportGroups`、`TestImportEndsTheOffer`、`TestImportRules`；手测 11.3。

## S3. 用系统听写作为语音识别模型

- **起点**：不想下载模型，或者磁盘空间不够。
- **操作**：语音识别模型页 → 本机 → 系统听写 → 设为转录的语音识别模型，然后转录一句。
- **应看到**：不需要下载；说话时浮窗里实时显示文字；结果按主语言识别（设置 → 通用里没设主语言时用 Mac 的语言）。
- **边界**：第一次使用时 macOS 请求“语音识别”权限（设置 → 权限里也能打开）；这台 Mac 不能在本机识别的语言会失败，并有通知说明原因；语音识别模型选“自动”时，仍然使用已下载的模型。
- **覆盖**：`TestModelsPageSystemDictation`、`TestSessionSystemDictation`、`TestLongDictation`；手测 2 节。

## S4. 设置一个远程语音识别服务

- **起点**：想用云端识别，例如豆包。
- **操作**：语音识别模型页 → 远程服务 → 豆包 → 填 key 和 App ID → 测试 → 保存，在转录页选它，转录一句。
- **应看到**：豆包、阿里云百炼、Gemini 在说话时实时显示文字（标有“实时”），其他服务在停止后出结果；设置好的服务出现在每个功能的语音识别模型菜单里，排在本机模型之后。
- **边界**：OpenAI Transcribe、阶跃星辰、智谱指向本机的服务（例如本机的 Whisper）时不需要 key；Mac 上没有语音识别模型时自动用设置好的远程服务；词典的词条作为热词或提示发给服务（小米 MiMo 不接收）；隐私说明里列出这些服务会收到音频。
- **覆盖**：`TestRemoteSpeechDoubaoFlash`、`TestLegacySpeechServicesKnown`、`TestPrivacyNamesSpeechServices`；手测 9.12、8.4。

## S5. 把模型放到另一个文件夹

- **起点**：系统盘空间不够，想把模型放到外接硬盘。
- **操作**：设置 → 存储 → 模型文件夹 → 更改…，选外接硬盘上的一个文件夹。
- **应看到**：Voxt 先把已有的模型迁移过去（同一块磁盘上用硬链接，不额外占用空间；不同磁盘之间复制），然后重启，存储页显示新路径，转录照常可用，不重新下载。
- **边界**：其他 ActNow app 的模型，不管原来放在哪里，都会一起迁移，之后那些 app 也使用新文件夹；旧文件夹保持不变，确认没有 app 再使用后，可以在访达里手动删除。
- **覆盖**：`TestModelFolderChange`、`TestModelFolderBringsOtherLibraries`；手测 9.7。

## S6. 调整远程语言模型的生成设置

- **起点**：已经设置好一个语言模型，想关掉思考或改温度。
- **操作**：打开服务的对话框 → “思考”选“关闭” → 展开“高级”，改温度，或在“请求参数”里写一个 JSON 对象 → 保存。
- **应看到**：只显示这个服务支持的字段；采样参数默认留空，输入框的占位文字是“服务默认”；“请求参数”在“高级”最后，Ollama 的占位文字是 `{"options": {"num_ctx": 8192}}`。
- **边界**：数字框填了非数字、“请求参数”不是 JSON 对象时不能保存，并指出是哪一项。
- **覆盖**：`TestRemoteGenerationSettings`、`TestGenerationFields`、`TestGenerationNumbers`、`TestGenerationThinking`、`TestGenerationDialogUntouched`；手测 9.10。

## S7. 只在菜单栏显示

- **起点**：不想让 Voxt 占用 Dock 的位置。
- **操作**：设置 → 通用 → 关掉“在程序坞中显示”（在“在设置中查找”里搜“Dock”或“程序坞”也能找到），然后关闭窗口，再从菜单栏图标打开。
- **应看到**：Dock 图标立刻消失，Voxt 窗口仍在最前面，菜单栏图标保持显示；从菜单栏图标能打开窗口和设置。在 Voxt 1.x 里关了“在 Dock 中显示”、用 2.0.0 或 2.0.1 装的 Voxt 2，更新后第一次启动也不在 Dock 里。
- **边界**：Dock 图标和菜单栏图标不会同时消失：如果之前关掉了菜单栏图标，关掉 Dock 图标时菜单栏图标会重新出现；之后再关掉菜单栏图标，Dock 图标会重新出现。中文界面下开关文字不截断。
- **覆盖**：`TestDockSwitch`、`TestDockInChinese`、`TestSettingsSearchFindsRows`、`TestLegacyDockAtStart`；手测 9.6、9.8b。

## S8. 结果同时复制到剪贴板

- **起点**：习惯转录后自己把结果粘贴到别处。
- **操作**：设置 → 通用 → 打开“同时把结果复制到剪贴板”，在 TextEdit 里转录一句，再按 ⌘V。
- **应看到**：结果插入 TextEdit，⌘V 粘贴出来的也是这次的结果；显示在答案卡片里的结果同样会被复制。
- **边界**：开关关闭时，插入后剪贴板恢复成原来的内容。
- **覆盖**：`TestCopyResult`；手测 9.6 第 4 条。

## S9. 浮窗不显示实时文字

- **起点**：共享屏幕或演示时，不想让说的话出现在浮窗里。
- **操作**：设置 → 浮窗样式 → 关掉“显示实时文字”，转录一句，再改写一段选中的文字。
- **应看到**：说话时和模型生成时，浮窗都不显示文字；结果照常插入，答案卡片照常显示结果。
- **边界**：关掉后再打开，下一次录音就会恢复显示实时文字。
- **覆盖**：`TestLiveTextSwitch`、`TestLiveTextCard`、`TestLiveTextNoLLMDraft`；手测 9.4、9.13。
