## Design Context

### Users

Voxt serves macOS users who rely on voice input, translation, rewriting, and meeting capture throughout daily work. They need focused workflows that stay fast and predictable while moving between apps.

### Brand Personality

Native, restrained, efficient. The interface should feel calm and dependable, with personality coming from precise interaction details rather than decorative UI.

### Aesthetic Direction

Follow macOS conventions and Voxt's shared settings components across light and dark appearances. Prefer compact hierarchy, system typography, neutral surfaces, subtle borders, and accent color reserved for selection and primary actions. Avoid one-off modal shells, nested cards, and custom controls when a shared component exists.

### Design Principles

1. Reuse shared dialog, control, spacing, and button patterns before introducing new UI.
2. Keep the primary task obvious and remove explanation or decoration that does not help complete it.
3. Preserve native macOS behavior, keyboard access, focus states, and light/dark appearance support.
4. Use restrained visual hierarchy: neutral surfaces for structure and accent color only for state or action.
5. Keep frequent voice and translation workflows compact, responsive, and predictable.
